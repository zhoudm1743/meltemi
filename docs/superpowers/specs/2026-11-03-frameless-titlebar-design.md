# 无边框窗口与自绘标题栏设计

## 目标

在现有 Go、GLFW、OpenGL 阶段 0 底座上，实现 Linux 优先的无边框窗口和可复用自绘标题栏。窗口不使用系统标题栏；图标、标题、最小化、最大化和关闭按钮由本库绘制并可配置样式。

## 已确认需求

- 通过 GLFW 禁用原生窗口装饰。
- 自绘标题栏、图标和窗口控制按钮。
- 支持最小化、最大化/还原和关闭。
- 支持标题栏拖动、标题栏双击最大化/还原。
- 支持窗口四边和四角拖拽调整大小。
- 支持按钮悬停和按下状态。
- 样式可以配置，不要求本轮接入尚未实现的 CSS 系统。

## 架构决策

- `driver.Config` 增加 `Frameless bool`，零值保持系统装饰窗口，避免破坏现有行为。
- 新增可选 `driver.FrameWindow` 接口，不扩大基础 `driver.Window`，避免无关后端和测试假件被迫实现窗口控制。
- `internal/windowframe` 提供布局、命中测试、样式和交互状态机，不直接依赖 GLFW 或 OpenGL。
- 新增 `cmd/wind-frameless` 作为真实集成演示，不修改阶段 0 的 `cmd/wind-stage0`。
- 本轮使用 `windowframe.Style` 配置颜色、标题栏高度、按钮宽度、缩放宽度和最小窗口尺寸；未来 CSS 系统读取同一组件属性。
- 使用现有矩形和文字渲染；不引入图片组件、透明圆角、阴影或新的渲染后端。

## 交互语义

- 左键按下窗口按钮时进入按下状态，释放时仍在同一按钮内才触发动作。
- 最小化调用原生 Iconify；最大化按钮根据当前状态选择 Maximize 或 Restore；关闭交给应用既有资源释放路径。
- 标题栏非按钮区域按下并移动可拖动窗口，双击切换最大化/还原。
- 四边和四角命中区域优先调整大小，按钮命中优先于边缘，标题栏剩余区域用于拖动。
- 调整大小不能小于样式声明的最小尺寸；左边和上边缩放时同步调整窗口位置，保持相对边缘位置稳定。
- 所有窗口控制和重绘仍只在 UI 线程执行；没有输入或尺寸变化时不持续重绘。

## 非目标

- 透明背景、圆角、原生阴影和跨合成器一致外观。
- Windows/macOS 的实际验收，但公共驱动语义不得阻碍后续实现。
- CSS 文件解析、主题热重载、可视化设计器。
- 多显示器拖动的完整平台特殊处理。
- 本轮不承诺真人手感、高 DPI 和所有 Linux 窗口管理器完全一致。

## 验收

1. 默认窗口仍有系统装饰，`Frameless: true` 的窗口没有系统标题栏。
2. 标题、图标和三个控制按钮由 OpenGL 绘制，悬停/按下样式有变化。
3. 最小化、最大化/还原和关闭调用正确的窗口行为。
4. 标题栏拖动、双击和四边四角缩放具有确定性单元测试。
5. 最小尺寸、按钮释放取消和缩放位置调整有测试。
6. 真实 Linux 窗口 smoke 自动完成控制操作、释放资源并退出；无法真人验证的观感或高 DPI 明确披露。
