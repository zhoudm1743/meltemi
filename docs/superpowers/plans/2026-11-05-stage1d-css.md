# Stage 1D CSS Subset and Component Styling Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 实现 CSS 子集解析、类型/class/ID/状态选择器、优先级与继承、组件 ID/Class、App.LoadStyles、字体注册、圆角绘制和真实登录样式演示。

**Architecture:** `internal/style` 负责保留顺序的 CSS 解析和选择器求值；公开 ui 组件只提供 ID/Class 元数据和状态。Window 负责注入解析后样式与按 App 隔离的字体，renderer 增加圆角矩形能力，代码显式布局配置始终优先于样式表。

**Tech Stack:** Go 1.26、既有公开 ui、内部 style/renderer/text/GLFW/OpenGL；不新增第三方依赖。

**Spec:** `docs/superpowers/specs/2026-11-04-text-input-css-ime-expanded-design.md` 的 1D 节及实施补充裁决。

## Global Constraints

- 不使用 Fyne、WebView、HTML 或 JavaScript，不新增依赖。
- 选择器仅支持一个类型/class/ID 加一个可选状态；不支持后代、逗号、属性选择器、伪元素、媒体查询、margin 或 `!important`。
- 优先级固定：代码显式设置 > ID+状态 > ID > class+状态 > class > 类型+状态 > 类型 > 默认主题；同优先级后者覆盖前者。
- 仅 `font-family`、`font-size` 和文字颜色允许继承，其他属性不继承。
- CSS width/height 只覆盖自然尺寸，不阻止 Column 拉伸；Go 的 Gap/Padding 等显式布局不被覆盖。
- 解析或字体名校验失败不得覆盖已加载样式；未注册字体不得悄悄替换为其他字体。
- 所有样式应用、字体生命周期和重绘只在 UI 线程。
- 当前非 Git 仓库，不自动初始化或提交；不使用 sudo。

## Review Focus

- 非法 CSS、未知属性、未注册字体：必须报位置明确的错误并保留旧样式；由 Task 1/4 的 `TestLoadStylesFailurePreservesPrevious` 固定。
- ID/class/类型与状态优先级：同优先级后者胜，代码显式 Gap/Padding 不被覆盖；由 Task 4 的 `TestCodeLayoutPriority` 固定。
- width/height 与 Column 拉伸：CSS 只改自然尺寸，不破坏 Go 布局；由 Task 4 的 `TestCSSSizeDoesNotOverrideColumnStretch` 固定。
- 字体按 App 隔离：两个 App 的同名不同字体数据不得串用，关闭时全部释放；由 Task 4 的 `TestFontRegistryIsolationAndCleanup` 固定。
- 圆角与裁剪：圆角背景和边框不能越界，Input 选择和文字仍按 clip 绘制；由 Task 3 的 `TestRoundedBorderAndInputClip` 固定。

- [ ] **Step 3: 实现 AST、选择器和声明解析**

```go
type SelectorKind uint8
const (
    TypeSelector SelectorKind = iota
    IDSelector
    ClassSelector
)

type State uint8
const (
    StateNone State = iota
    StateHover
    StateFocus
    StateDisabled
    StateChecked
    StatePressed
)

type Selector struct { Kind SelectorKind; Name string; State State }
type Property struct { Name, Value string; Line, Column int }
type Rule struct { Selector Selector; Properties []Property; Line int }
type Sheet struct { Rules []Rule }
func Parse(r io.Reader) (*Sheet, error)
```

保留规则及声明顺序，支持 CSS 注释和分号。类型名支持 Column、Label、Button、Input、Password、TextArea；`.class` 和 `#id` 只允许一个标识符，状态可选且只能一个。`font-family` 支持标识符或单引号/双引号字符串，`font-size` 使用 px。

- [ ] **Step 4: 实现颜色、尺寸与 border/padding 值**

`ParseColor` 支持 #RGB、#RRGGBB、#RRGGBBAA 和 white/black/transparent/red/green/blue/gray。`ParseDimension` 支持 0 和 px，其他单位/百分比报错。border 仅支持 `<width> solid <color>`，padding 支持 1-4 个尺寸。
