# Meltemi 兼容性矩阵（阶段 2 实测）

本文档只记录**实际运行过**的验证结果。每个能力按证据等级标注：

- **自动化**：无头/假后端单元测试与集成测试（`go test`）。
- **协议 smoke**：真实桌面上的有界演示程序（`--smoke`）验证协议与公共 API 路径。
- **视觉/人工**：真实屏幕截图或人工目检。
- **未验证**：本机没有对应环境或尝试被阻断，**不以 Linux 实现推断其他平台/桌面通过**。

验证环境（本机唯一实测环境）：Deepin 23（DDE，dde-shell）、X11 `DISPLAY=:0`（单显示器
3440x1440，96 dpi）、Fcitx 5（默认搜狗拼音，`rime` 可用）、`org.freedesktop.portal.Desktop`
在线（dde + gtk 后端）、NVIDIA GeForce GTX 1050 Ti（驱动 580.119.02，OpenGL 4.6.0）、
Intel Core i5-10400、Go 1.26.4 linux/amd64。验证日期：2026-11-09。

复现命令（在仓库根目录）：

```bash
go test ./... -count=1
go test -race -gcflags=all=-d=checkptr=0 ./internal/render/gl ./internal/text ./ui -count=1
go test -race ./internal/desktop ./internal/xim -count=1
go vet ./...
go build -o /tmp/meltemibin/ ./cmd/meltemi-layout ./cmd/meltemi-menu ./cmd/meltemi-tray ./cmd/meltemi-dialog ./cmd/meltemi-text ./cmd/meltemi-ime
DISPLAY=:0 /tmp/meltemibin/meltemi-layout --smoke      # exit 0
DISPLAY=:0 /tmp/meltemibin/meltemi-menu --smoke        # exit 0
DISPLAY=:0 /tmp/meltemibin/meltemi-tray --smoke        # exit 0
DISPLAY=:0 /tmp/meltemibin/meltemi-dialog --smoke      # exit 0（打印 smoke: OK）
DISPLAY=:0 MELTEMI_GLFW_DESKTOP_TESTS=1 /tmp/meltemibin/meltemi-text --smoke   # exit 0
DISPLAY=:0 MELTEMI_GLFW_DESKTOP_TESTS=1 /tmp/meltemibin/meltemi-ime --smoke    # exit 0（完整 PASS；smoke 模式内设 KeepRunning，见 IME 行）
```

## 已知限制与失败（保留，不隐藏）

1. **`meltemi-ime --smoke` Hide 步骤失败（2026-11-09 发现，当日已修复，诊断保留）**：当日验证时 smoke 在 `second composition cancelled by Escape` 之后、Hide 验证步骤处打印 `meltemi-ime: meltemi-ime: Run returned before smoke validation completed`（程序输出含双重 `meltemi-ime:` 前缀：外层 `main` 打印、内层错误串自带）并 exit 1（2/2 复现；证据日志见报告 RED 记录）。根因：`ui/window.go` `hide()` 在 `visibleWindowCount()==0` 时触发 `applyLastWindowPolicy()`，默认 `LastWindowQuit` 使 `Run` 在 smoke 中段 `win.Hide()` 时返回；该 smoke 编写于「Hide 不触发最后窗口策略」的旧语义时代（stage1e，2026-11-05），语义变更来自 stage1-menus-windows（2026-11-06，有意的托盘恢复设计，**产品策略保持不变**）。修复（仅 smoke 配置，`cmd/meltemi-ime/main.go`）：`--smoke` 时在 `app.Run` 前调用 `app.SetLastWindowAction(ui.LastWindowKeepRunning)`，并在 smoke 成功完成后显式 `app.Quit()`；普通演示模式不设 KeepRunning（最后窗口关闭即退出，不留驻留进程）。修复后完整 `SMOKE PASS`，exit 0；全部既有输入断言保留未动。
2. 托盘原生菜单弹出依赖宿主：dde-shell 溢出面板点击未唤起 dbusmenu（见矩阵托盘行）；旧 DDE dock 与 GNOME/KDE 宿主行为未实测。
3. 当日晚间 4 次尝试补拍原生文件选择器均未弹出（见矩阵对话框行）；视觉证据为当日上午截图。
4. 屏幕采集受远控合成器影响：x11grab 帧相对真实 X 坐标存在约 47px 纵向偏移且偶发陈旧帧，托盘图标配色定位（橙色 variant）即为此设计；所有坐标敏感结论均以 `xdotool getmouselocation` 的窗口反馈为准。
5. `-race` 对 `internal/render/gl` 需要 `-gcflags=all=-d=checkptr=0`（go-gl `PtrOffset` 的 checkptr 误报，基线快照同样如此，非本阶段引入）。
6. `cmd/meltemi-stage0/main_test.go` gofmt 基线即未格式化（多个计划记录，未触碰）。
7. 文件对话框计划遗留：1 次未复现的 race 模式功能失败（该计划 task-1 记录，无保留日志，之后多次 race 运行未出现）。
